# 食乜好 - What to Eat 🍱✨

[![PWA](https://img.shields.io/badge/PWA-Ready-orange)](https://what2eatnow.org/)

一個為「唔知食乜好」嘅你而設嘅輕量級 PWA 網頁應用。透過 Google Maps API 實時搜尋附近餐廳，幫你快速做出決定！

A lightweight PWA for when you can't decide what to eat. Search for nearby restaurants in real-time using Google Maps API and make quick decisions!

「何を食べようか」と迷っているあなたのための軽量PWAウェブアプリ。Google Maps APIを使用して周辺のレストランをリアルタイムで検索し、素早い決断をお手伝いします！
